# quanttide-tutorial-of-search-engineering

量潮搜索工程教程——从零写一个搜索程序的入门教程。

## 概述

本仓收录搜索工程领域的教程。`intro/` 是入门系列，第一篇从空项目开始，一步步写出一个能跑的中文搜索程序，再用「评测 → 改一处 → 重跑」把它调准。

原始对话与草稿在语境仓 `context/tutorial/`，整理成稿后移入本仓。写法见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。

## 内容

| 主题 | 讲什么 | 位置 |
| :-- | :-- | :-- |
| 从零写一个搜索程序 | 建项目、索引与打分、中文分词、评测与改写构成的最小循环 | [`intro/loop.md`](intro/loop.md) |
